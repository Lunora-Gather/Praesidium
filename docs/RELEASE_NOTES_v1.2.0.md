# Praesidium v1.2.0

## 界面和战斗

- 选关页显示真实地图、路线和解锁条件，切换锁定关卡时保持布局稳定。
- 战斗棋盘加强可建区域、路线和出入口的区分。敌军和炮塔使用不同轮廓，战场、商店和情报图鉴共用同一套图形。
- 每日任务、周挑战和成就集中在作战简报。统计页按实际数据展示概览，排行榜明确区分个人本地纪录和模拟对手。
- 手机上的小地块可先预览再确认。出售和施法提供确认，陨石落点范围内没有敌军时保留金币和冷却。

## 性能和偏好

- 提供自动、清晰、省电画质和可预览的震动滑杆。减少动效优先于震动强度。
- 暂停时减少重复绘制、存档和音频调度。自动画质根据实际帧间隔调整画布分辨率。

## 升级与存档

在旧版本内保存或结束对局，关闭守望的全部标签页，再从同一网址打开。1.2.0 支持上一版的 IndexedDB 进度与对局。恢复的对局先暂停，继续后使用保存的倍速。可在「设置 → 管理本地进度」备份或恢复。

发布验证使用 `npm run verify`、`npm run verify:browser`、`npm run perf:browser` 和 `npm run verify:pages`。线上构建与验证记录见[部署状态](DEPLOYMENT_STATUS.md)。
