# Praesidium v1.1.0 发布说明

正式网页版：https://lunora-gather.github.io/Praesidium/

## 主要变更

- 进度、结算和续局改用事务存储。续局接管、替换前会确认；设置中可导出和恢复战役、天赋、纪录和续局。
- 战役、无尽、每日、每周和分享练习分别计分。P2 分享码保留种子、起始配置、规则与计分版本；旧 P1 码仍可练习，旧纪录不会混入新计分榜。
- 窄屏保留发波、自动发波和作战简报。较小的触屏地块先预览、再点按确认。设置可减少动效，教程可以重看。
- 已缓存的完整版本可以离线启动；更新不强制中断战斗，新资源不齐时不会和旧资源混用。

## 从 1.0.0 更新

如果游戏提示等待完成更新，先保存或结束原来的对局，再关闭所有守望标签页并重新打开。迁移会保留原始数据，不需要清除浏览器存储。旧续局的恢复精度取决于旧版已经记录的内容。若需要换设备，在设置中先导出备份。

## 验证与发布范围

发布前应通过 `npm run verify`、`npm run verify:browser` 和 `npm run release:gate`，并核对线上版本和资源。真机触控、VoiceOver、长时功耗和外部试玩不等同于桌面浏览器回归。详细范围与候选截图见 [优化候选版验收](OPTIMIZATION_VERIFICATION.md)。
